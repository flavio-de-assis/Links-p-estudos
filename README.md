# 🔗 Links para Estudos — Flávio De Assis

Projeto pessoal criado para centralizar links úteis para estudo de **programação e tecnologia**, organizados por linguagem e área de conhecimento.

👉 **Acesse o projeto:**  
🔗 https://flavio-de-assis.github.io/Links-p-estudos/

---

## 🎯 Objetivo do Projeto

Este projeto tem como objetivo:

- Centralizar links de estudo em um único lugar
- Facilitar o acesso a materiais confiáveis de aprendizado
- Organizar conteúdos por linguagem e área
- Servir como apoio contínuo para estudos em tecnologia

---

## 🧠 Sobre o Projeto

A página reúne links para plataformas, documentações e materiais de estudo relacionados a:

- Front-end
- Back-end
- Linguagens de programação
- Fundamentos de tecnologia

O projeto foi desenvolvido com foco em simplicidade, organização e fácil navegação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura da página
- **CSS3** — Estilização e layout responsivo
- **Google Fonts** — Tipografia
- **GitHub Pages** — Publicação do projeto

---

## 🎨 Funcionalidades

- Layout em grid com cards organizados
- Design responsivo
- Navegação simples e intuitiva
- Links diretos para plataformas de estudo
- Visual limpo e consistente
